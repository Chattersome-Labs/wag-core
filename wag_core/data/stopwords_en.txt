# stopwords_en.txt - recommended English "glue word" exclude list for wag_core
#
# Low-information function words, contractions, conversational fillers, and
# profanity intensifiers that are almost never the *core subject* of a topic in
# any community. Excluding them before graph construction keeps anchor-word
# harvesting focused on topical vocabulary.
#
# ENGLISH ONLY. wag_core is language-agnostic and applies NO word list by
# default. Opt in for English corpora with `--exclude-words builtin:en`
# (or point --exclude-words at this file). For other languages, omit it or
# supply your own list.
#
# Design principle: a word belongs here only if it could never be the core
# subject of a topic in ANY community. Domain words (e.g. "cancer", "insulin")
# and even time-generics ("days", "years") are deliberately EXCLUDED from this
# list and left to wag_core's per-corpus dynamic pruning - because an omission
# self-heals (dynamic pruning still catches it where it is noise) but a wrongful
# exclusion silently deletes signal everywhere, in every corpus.
#
# Contractions appear in ASCII ('), curly (’), and apostrophe-stripped (dont)
# forms because the tokenizer preserves internal apostrophes verbatim.
#
# One word per line; blank lines and lines starting with '#' are ignored.
# See https://github.com/Chattersome-Labs/wag-core
#
